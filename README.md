# MechCraft 3D

웹 기반의 3D 기계 설계 및 모델링 뷰어입니다. Three.js를 활용하여 브라우저에서 바로 기계 부품을 조립하고 확인할 수 있습니다.

## 주요 기능
- **3D 뷰어**: 마우스를 이용한 자유로운 회전, 이동, 확대/축소 지원 (OrbitControls)
- **부품 추가**: 육면체, 원기둥 등 기본 도형 지원
- **기계 요소**: 스프링, 모터 등 복합 구조물 추가 가능
- **상업/개인 범용성**: 브라우저만 있으면 어디서든 실행 가능한 가벼운 환경

## 사용 기술
- HTML5, CSS3, JavaScript (ES6 Modules)
- [Three.js](https://threejs.org/) (3D WebGL Library)

## 실행 방법
따로 빌드할 필요 없이 웹 서버를 통해 `index.html`을 실행하면 됩니다.
VS Code를 사용하신다면 `Live Server` 확장을 통해 쉽게 띄울 수 있습니다.
